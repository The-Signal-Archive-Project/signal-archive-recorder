Signal Archive Recorder for Debian and Ubuntu

Signal Archive Recorder runs beside WSJT-X and records exactly what your receiver hears, for the Signal Archive Project's open dataset of real radio signals. Adding this repository lets apt install it and keep it up to date. It works on Debian 12 or newer and Ubuntu 22.04 or newer (64-bit PC).

Stable (most people)

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL {site}/signal-archive.asc | sudo tee /etc/apt/keyrings/signal-archive.asc > /dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/signal-archive.asc] {site} stable main" \
  | sudo tee /etc/apt/sources.list.d/signal-archive.list
sudo apt update && sudo apt install signal-archive-recorder

Currently: {stable}

Beta (testers)

The same, with beta in place of stable. You get the newest beta, or the newest release once it's newer than every beta.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL {site}/signal-archive.asc | sudo tee /etc/apt/keyrings/signal-archive.asc > /dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/signal-archive.asc] {site} beta main" \
  | sudo tee /etc/apt/sources.list.d/signal-archive.list
sudo apt update && sudo apt install signal-archive-recorder

Currently: {beta}. Beta recordings go to a test dataset; see the tester guide.

Afterwards

Updates arrive with your normal sudo apt update && sudo apt upgrade. Start Signal Archive Recorder from your applications menu. To switch channels, run the echo line again with the other channel name, then sudo apt update. To stop using this repository: sudo rm /etc/apt/sources.list.d/signal-archive.list /etc/apt/keyrings/signal-archive.asc.

Packages are signed with the key 9EC6 4E0C 1693 2FCC C381 381C 38FA 930D 4522 E702 (Signal Archive Project packages). Questions: groups.io/g/signal-archive.
