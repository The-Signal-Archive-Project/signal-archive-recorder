# Security

If you find a problem that could expose someone's Hugging Face token, their data, or anything else that shouldn't be public, please **don't open a public issue**. Report it privately instead:

**[Report a vulnerability](https://github.com/The-Signal-Archive-Project/signal-archive-recorder/security/advisories/new)** (GitHub's private reporting)

We'll reply as soon as we can, and credit you when the fix is released if you'd like.

Signal Archive Recorder keeps the token only in your operating system's keyring, never in files or logs, and diagnostics files have names and tokens removed. Reports about any way around that are especially welcome.
